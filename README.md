# 🛠️ دليل الأردوينو العملي (Arduino Kids Practical Guide)

مجموعة دروس عملية مصوّرة للأردوينو موجّهة للمبتدئين (الأطفال واليافعين)، تنتقل بهم خطوة بخطوة من إضاءة لمبة بسيطة إلى بناء مشاريع إلكترونية متكاملة تعتمد على المستشعرات والتواصل بين لوحات الأردوينو.

المحتوى مكتوب باللغة العربية بأسلوب شبيه بالقصة، مع رسوم بيانية، جداول منطقية (Truth Tables)، وأكواد جاهزة قابلة للنسخ.

| شاشة الأرقام السباعية | `seven_segment_guide.md` | التحكم بـ 7-Segment Display وعرض الأرقام من 0 إلى 9 |
| المقاومة المتغيرة ومحرك السيرفو | `servo_potentiometer.md` | التحكم الدقيق بالإضاءة والمحركات عبر الـ Potentiometer و PWM |

| لوحة المفاتيح المصفوفية 3×4 | `matrix_keypad_3x4.md` | قراءة 12 زراً بـ 7 أرجل فقط وبناء خزنة بكلمة سر |

## 🎯 الهدف العام للمشروع

تمكين المتعلّم المبتدئ من ربط **العالم المادي** (مستشعرات، أزرار، مقاومات) بـ **التحكم البرمجي الدقيق** على لوحة الأردوينو، وبناء فهم تراكمي يبدأ بالمكوّنات البسيطة وينتهي بالتواصل بين الأجهزة. الدروس مُصمّمة لتُدرَّس بالترتيب لأن كل درس يبني على ما سبقه.

## 🧩 ملخص كل درس وهدفه

### 1) شاشة الأرقام السباعية (7-Segment Display)
- **المحتوى:** شرح بنية الشاشة (7 لمبات a–g)، الفرق بين الكاثود المشترك والأنود المشترك، مخطط التوصيل بالمقاومات 220Ω، جدول المنطق للأرقام 0–9، وطريقتين للبرمجة (مباشرة بـ `digitalWrite`، وعالية السرعة باستخدام السجلات `PORTD`/`PORTB`).
- **الهدف:** تعليم عرض الأرقام برمجياً وبناء عدّاد رقمي، وفهم أساس سيُعاد استخدامه لاحقاً في عرض قراءات المستشعرات.

### 2) المقاومة المتغيرة ومحرك السيرفو (Potentiometer & Servo)
- **المحتوى:** مفهوم الإشارات التماثلية (Analog 0–1023)، تقنية PWM للتحكم بشدة الإضاءة، دالة `map()` لتحويل النطاقات، واستخدام مكتبة `Servo.h` لتحريك ذراع السيرفو بدقة بين 0 و180 درجة.
- **الهدف:** الانتقال من التحكم الرقمي (تشغيل/إطفاء) إلى التحكم التدريجي الدقيق في الإضاءة والحركة الميكانيكية.

### 3) مستشعر الحرارة LM35
- **المحتوى:** آلية عمل مستشعر LM35DZ (10mV لكل °C)، قراءة الحرارة عبر `analogRead` وعرضها على Serial Monitor، ثم عرضها على شاشة 7-Segment كجهاز مستقل، ثم إضافة إنذار حراري بـ LED عند تجاوز حد معين.
- **الهدف:** تعليم الأردوينو "الإحساس" بالبيئة تلقائياً واتخاذ قرار (If/Else) بناءً على قراءة مستشعر، مع التدرّب على تحويل الإشارات التماثلية إلى قيم حقيقية.

### 4) التواصل التسلسلي UART
- **المحتوى:** بروتوكول UART (TX/RX)، ربط أردوينو بأردوينو، تقنية Pull-Down للمفاتيح، إرسال أوامر `'H'`/`'L'` للتحكم بـ LED عن بُعد، مع تحديات (تحكم متبادل، زر تبديل، رسائل كاملة).
- **الهدف:** بناء أول شبكة تواصل بين جهازين، وفهم الأساس الذي تقوم عليه كل تقنيات الاتصال اللاحقة (الريموت، البلوتوث، WiFi، الإنترنت).

### 5) بطاقة تحريك المحركات (L9110S Motor Driver)
- **المحتوى:** لماذا لا نوصّل المحرك مباشرة بالأردوينو، مشغّل المحركات L9110S ودائرة عكس التيار، التحكم بالاتجاه (أمام/خلف/توقف) وحفظ حالة المحرك، ثم التحكم بالسرعة عبر PWM، ومشروع ختامي لسيارة تتجنّب الحائط.
- **الهدف:** تحويل الأردوينو من "مفكّر صغير" إلى "قائد آلة" يتحكم بمحركات DC الحقيقية باتجاه وسرعة، مع فهم أساسيات الطاقة والأمان.

### 6) لوحة المفاتيح المصفوفية 3×4 (Matrix Keypad)
- **المحتوى:** فكرة المصفوفة (12 زراً بـ 7 أرجل)، بناء الماسح يدوياً مع مقاومات السحب للأسفل، ثم الطريقة الاحترافية بمكتبة `Keypad` و `INPUT_PULLUP` بدون مقاومات، ومشروع ختامي: خزنة سرية بكلمة مرور تُفتح بالسيرفو.
- **الهدف:** تعليم تقنية المسح المصفوفي (Scanning) المستخدمة في الكيبوردات والصرافات الآلية، والانتقال من قراءة زر واحد إلى واجهة إدخال كاملة.

## 🚀 كيفية التشغيل والبناء

### معاينة الموقع محلياً (MkDocs)
```bash
pip install mkdocs-material
mkdocs serve        # يعرض الموقع على http://127.0.0.1:8000
mkdocs build        # يولّد مجلد site/ الجاهز للنشر
```

### توليد نسخة PDF للأطفال (Pandoc + Typst)
```bash
pandoc seven_segment_guide.md -o lesson.pdf \
  --pdf-engine=typst \
  --template=kids_template.typ
```
